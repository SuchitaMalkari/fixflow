How it decides

The LLM handles language. Plain, testable code makes the final call, and safety rules sit outside the model so it can only become more careful.

RetrieveBM25 search, built from scratch, over the troubleshooting articles.
TriageCategory, urgency and confidence as schema-validated JSON.
CheckWarranty and plan looked up by serial number.
DecideSafety, security, low confidence → a person. Damage or outages → a ticket.
ExplainAnswer with citations, plus a trace of every step.

Measured, not assumed

50 hand-labeled tickets: 20 for tuning, 30 held out and run once. CI fails the build if quality drops.
