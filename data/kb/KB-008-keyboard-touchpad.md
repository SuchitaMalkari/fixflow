# Keyboard keys, touchpad or trackpoint not working

## Symptoms
Some keys do not type or type the wrong characters, the keyboard is completely unresponsive, the touchpad does not move the cursor, or the cursor jumps around.

## Quick fix
1. Press the touchpad toggle key (often F6 or Fn + F6) in case the touchpad was switched off.
2. Check that Filter Keys and Sticky Keys are off in Settings > Accessibility > Keyboard.
3. Check the keyboard layout in Settings > Time & language > Language & region if keys type the wrong characters.
4. Reinstall the keyboard and touchpad drivers from Device Manager, then restart.
5. Try an external USB keyboard or mouse to see if the problem is the built-in hardware.

## When to open a ticket
Keys that are physically stuck, missing or damaged by liquid need Hardware Repair. Liquid spills should be reported straight away.
